Brand Identity Guide

Project

Denial Management KPI Dashboard

Owner

Kori Pickle

Brand purpose

This project uses a Tennessee-rooted healthcare operations identity. The visual system should feel clean, professional, operational, and credible for healthcare administration, revenue cycle management, workflow analysis, and KPI dashboard work.

Brand colors

Tennessee Orange

Hex: #FF8200

Use for:

- KPI emphasis
- section dividers
- dashboard callouts
- active states
- visual priority markers
- operational urgency indicators

Smokey Gray

Hex: #4B4B4B

Use for:

- secondary text
- table borders
- supporting labels
- notes
- inactive states
- structural separation

Black

Hex: #0A0A0A

Use for:

- headings
- dark dashboard headers
- executive presentation backgrounds
- primary text when used on white
- high-contrast sections

White

Hex: #FFFFFF

Use for:

- main document backgrounds
- clean dashboard cards
- tables
- whitespace
- readable content areas

Visual identity rules

Use clean executive layouts.

Use Tennessee Orange sparingly. It should guide attention, not overwhelm the page.

Use black and white for structure and readability.

Use Smokey Gray for secondary information.

Keep visual hierarchy clear:

1. Black for authority
2. Orange for urgency and emphasis
3. White for clarity
4. Gray for support text

Tone and positioning

The brand should communicate:

- healthcare operations discipline
- revenue cycle awareness
- workflow clarity
- practical problem-solving
- patient-to-professional perspective
- Tennessee-rooted professional identity
- remote-ready administrative capability

Avoid

- random accent colors
- decorative visual clutter
- vague corporate language
- excessive graphics
- generic template styling
- colors outside the brand palette unless needed for accessibility or status labels

Dashboard styling rules

For dashboards:

- Use a black header with Tennessee Orange accent line.
- Use white KPI cards with orange top borders.
- Use gray labels for supporting text.
- Use black text for main values.
- Use orange for active tabs and priority markers.
- Keep tables simple and readable.

GitHub styling rules

For GitHub documentation:

- Use clear section titles.
- Explain the project as healthcare operations proof.
- Include the simulated-data and no-PHI disclaimer.
- Connect the work to RCM, workflow analysis, KPI tracking, denial prevention, queue management, escalation logic, and trust-layer monitoring.

Portfolio identity statement

This project is part of Kori Pickle’s healthcare operations portfolio. It demonstrates practical healthcare administration capability through simulated revenue cycle workflows, denial management logic, KPI tracking, upstream defect analysis, and operational trust monitoring.
